## 🎯 Зачем это вообще

Если вы летаете чаще, чем раз в месяц, то знаете эту боль:

- Открыть **Aviasales**, **Trip.com**, **WayAway**, **MyTrip**, **OneTwoTrip** — везде свои фильтры, везде свои цены.
- Помощница тратит **час** на поиск "Москва на майские из Екб подешевле".
- Сами условия "с пятницы по воскресенье любая страна, лишь бы недорого" в UI ни одного из этих сайтов не выражаются. Никак.
- Stopover-комбо ("дешевле прямого через Стамбул с 2 днями там в подарок") никто не подсветит.

**Этот репозиторий решает задачу по-инженерному**: один API, несколько хорошо подобранных запросов, ранжированная выдача в терминал. Без браузеров, без сетки вкладок, без человеческого фактора.

| Скрипт | Что делает | Зачем |
|---|---|---|
| [travelpayouts_search.py](travelpayouts_search.py) | Поиск по направлению / стоповер через хабы | Базовый поисковик с реальными ценами |
| [weekend_search.py](weekend_search.py) | 4 режима: `route`, `discover`, `abroad`, `longtrip` | Закрывает 90% реальных сценариев путешественника |

Все скрипты — **<800 строк Python**, без фреймворков, одна зависимость (`httpx`), CLI в стиле UNIX.

## 🛠 Возможности — все 6 сценариев с реальными выдачами

### 1️⃣ Поиск по направлению (с веером по аэропортам РФ)

```bash
python travelpayouts_search.py --from UBN --to RU --date 2026-05-19 --sort price --currency usd
```

Дёргает Travelpayouts параллельно по 11 крупным городам РФ от заданного origin, сортирует по цене.

```
1   216.00 USD   1h00m    0  IrAero    UBN > IKT  Иркутск ⭐ ближайший
2   271.00 USD   3h45m    1  IrAero    UBN > UUD  Улан-Удэ
3   402.00 USD  17h10m    1  IrAero    UBN > SVO  Москва
```

### 2️⃣ Stopover Hunter — перебор пересадочных хабов

```bash
python travelpayouts_search.py --stopover --from UBN --to MOW --depart 2026-05-19 --stop-days 2 --sort price
```

Перебирает 15+ азиатских и ближневосточных хабов (ICN, PEK, IST, DXB, DOH, ALA, TAS...), считает суммарную стоимость двух плеч с 2-дневной остановкой, ранжирует.

```
1   412.00 USD  13h40m   UBN > IST → 2 дня Стамбул → VKO   MIAT + Победа ⭐
2   564.00 USD   8h35m   UBN > ALA → 2 дня Алматы → SVO   Air Astana + Аэрофлот
3   572.00 USD  28h55m   UBN > PEK → 2 дня Пекин → SVO    MIAT + Air China
```

Видно, что Стамбул-стоповер **дешевле прямого** UBN→SVO ($402). То есть страна-бонус идёт **в подарок**.

### 3️⃣ Weekend по конкретному маршруту

```bash
python weekend_search.py route --from SVX --to AER --months 2026-05,2026-06,2026-07,2026-08
```

Перебирает все пятницы-воскресенья в заданных месяцах для маршрута A↔B. Покажет, какие даты дешевле, какие дороже.

Пример с SVX↔AER: цена за уикенд растёт с $87 в мае до $500 в августе. Если хочется летать каждый месяц — сразу ясно, какие даты ловить.

### 4️⃣ Discover — куда дёшево из вашего города

```bash
python weekend_search.py discover --from SVX --months 2026-05,2026-06,2026-07,2026-08 --top 25
```

Для каждой пятницы дёргает `/v1/prices/cheap` (популярные направления из origin) и собирает лучшие weekend-варианты по всем городам в кеше TP. Возвращает топ-N.

```
1   IJK   Ижевск       73 USD   I8 прямой
2   AER   Сочи         87 USD   Победа прямой ⭐
3   UFA   Уфа          97 USD   UTair прямой
...
17  EVN   🇦🇲 Ереван  204 USD   FlyOne прямой   ← первое международное
21  MMK   Мурманск    240 USD
24  MSQ   🇧🇾 Минск   256 USD
```

### 5️⃣ Abroad — международные выходные (курируемый список из 50+ направлений)

```bash
python weekend_search.py abroad --from SVX --months 2026-05,2026-06,2026-07,2026-08 --top 30
```

В отличие от `discover` использует **курируемый список 50+ международных направлений** (СНГ, Турция, Залив, Африка, Балканы, Европа, Азия) и пробивает их **все** на каждый выходной заданных месяцев. Решает проблему "TP кеш не вернул многие зарубежные маршруты".

Полная выдача — в [Quick demo](#-quick-demo--реальные-находки-за-5-минут-работы) выше.

### 6️⃣ Long Trip — недельные/двухнедельные поездки с flex-датами

```bash
python weekend_search.py longtrip \
  --from MOW --dests AU \
  --months 2026-06,2026-07,2026-08 \
  --nights 9 --flex 1 \
  --depart-dow 4
```

Для каждой пятницы лета генерит 9 комбинаций дат (±1 день на каждый край), пробивает по всем австралийским городам. **936 запросов выполняются за 2 минуты параллельно.**

Алиас `AU` разворачивается в SYD/MEL/BNE/PER/ADL/OOL/CNS/DRW. Можно подставить любые IATA вручную.

## 🧠 Почему именно Travelpayouts (и почему не Duffel/Amadeus)

Прежде чем остановиться на TP, мы протестировали все живые варианты. Вот честное ранжирование на май 2026:

| API | Балл | Реальные цены | Доступ для РФ | Прямая покупка | Покрытие СНГ |
|---|---|---|---|---|---|
| **Travelpayouts** ✅ | **10/10** | ✅ | ✅ без KYC | ❌ редирект на OTA | ✅ отличное |
| Duffel (test) | 5/10 | ❌ симулятор | ✅ | — | слабое |
| Duffel (live) | 9/10 | ✅ | ❌ блокируется Stripe KYC | ✅ | хорошее |
| Amadeus Self-Service | — | — | — | — | закрывается **17.07.2026** ([источник](https://www.phocuswire.com/amadeus-shut-down-self-service-apis-portal-developers)) |
| Skyscanner Partners | 3/10 | — | ❌ закрытая программа | — | — |
| Kiwi Tequila | 6/10 | ✅ | ⚠️ только партнёр | ✅ | средне |
| RapidAPI обёртки | 4/10 | ⚠️ нестабильно | ✅ | ❌ | непредсказуемо |

**Итог:**
- 🇷🇺 **Российский пользователь:** Travelpayouts — единственный API, дающий **реальные цены** и **0 барьеров на вход**.
- 🌍 **Зарубежная компания:** Duffel — полноценная автопокупка по NDC, но нужен Stripe-совместимый бизнес-аккаунт (UK/EU/US/AU/etc.).
- ❌ **Duffel-реселлеров не существует** — проверяли. Никто не перепродаёт Duffel-токены как сервис.

## 🇷🇺 Особенности для пользователей из России

Знание этих ловушек экономит часы дебага.

### IATA-коды, которые многие API не знают / переименовали
- **`ULN` → `UBN`** — Улан-Батор переехал в новый аэропорт Чингисхан (2021). Старый код `ULN` Travelpayouts отдаёт `400: not flightable`. Используйте `UBN`.
- **`FRU` (Бишкек)** — не в каталоге TP, возвращает `400`. Альтернатива не найдена.
- **City-codes vs airport-codes:** `MOW` агрегирует SVO+DME+VKO+ZIA, `MIL` = MXP+LIN+BGY, `BAK` = GYD. Используйте городские коды для широкого поиска.

### Платёжный потолок Duffel
Live mode Duffel = KYC через Stripe, **Stripe не работает с РФ-бизнесом**. Обход — открыть юрлицо в Казахстане / UAE / Грузии / Армении / Сербии / Эстонии. Бесполезно пробовать обходные пути из РФ — упрётесь.

### Travelpayouts: cached vs live
Endpoint `/aviasales/v3/prices_for_dates` и `/v1/prices/cheap` возвращают **кешированные цены**. Это значит: быстро (миллисекунды), но кеш **не покрывает все маршруты и даты** — особенно экзотику.

Если для маршрута A→B возвращает 0 офферов, **это не значит "рейса нет"**, это значит "TP не успел закешировать". Решение — Flight Search API v1 (асинхронный, через signature + polling). **На roadmap.**

## 🚧 Roadmap — что мы хотим добавить дальше

Идеи отсортированы по соотношению **польза × реалистичность**.

### Этап 1 — быстрая ценность (1-2 часа каждое)
- [ ] **Calendar heatmap** — ценник по каждому дню месяца на тепловой карте. Сразу видно, какой день недели лететь дёшево.
- [ ] **Free stopover finder** — алгоритм находит маршруты, где `A→B→C` дешевле или равен `A→C`. Стоповер фактически в подарок.
- [ ] **Visa-free filter** — к discover/abroad прикрутить фильтр "только страны, доступные с РФ-паспортом без визы".
- [ ] **`--direct-only` для weekend** — без пересадок, чтобы не убивать уикенд транзитом.

### Этап 2 — cron-инфраструктура (выходного дня каждое)
- [ ] **Price drop tracker** — следим за интересными маршрутами, пингуем в Telegram при падении цены >10%. Запуск через `cron` или `/schedule`.
- [ ] **Error fare hunter** — копим историю цен в SQLite, алертим при цене <50% от медианы по маршруту за 30 дней.

### Этап 3 — умные маршруты
- [ ] **Trip-stacker** — оптимизация суммарной стоимости из M городов через N остановок ("UBN→Москва→Дубай→UBN: найди минимум").
- [ ] **Open-jaw** — туда из A в B, обратно из C в D. Часто дешевле round-trip на 20-30%.

### Этап 4 — украшения
- [ ] **Telegram-бот** поверх всего этого — голосовое "найди мне выходные в Турцию до $300".
- [ ] **Climate-aware discover** — интеграция с OpenWeather для запросов "куда дёшево, где +25°C".
- [ ] **Lowcost-only filter** — фильтр перевозчиков (Победа / Pegasus / FlyOne / Wizz).
